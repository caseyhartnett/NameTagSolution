This is the unmodified Liberation Sans Bold font from Liberation Fonts 2.00.1,
distributed with the tested OpenSCAD development build. Its SIL Open Font
License 1.1 is included as `LICENSE.txt`. Font copyright remains with the
copyright holders named there.

`name_tags.scad` registers this local TTF with `use <fonts/LiberationSans-Bold.ttf>`.
The required family/style is `Liberation Sans:style=Bold`. Do not substitute a
different font if matching existing label widths matters. The Python `doctor`
command checks the included font hash and a fictional John Smith test label.
