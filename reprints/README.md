# Ready-to-open fictional sample tags

**Fictional sample data; not a roster of real people.**

`fake_names_plates.zip` contains a small demonstration batch generated from
`examples/fake_names.json`. Extract it and open its numbered model 3MF plates
separately in a slicer. `fake_names_preview.png` shows all sample labels at
one physical scale. The duplicate John Smith tag is intentional.

The files use the standard 16.69 mm Liberation Sans Bold scale, 50.8 mm height,
2 mm thickness and 0.8 mm black face. Width follows each label's text.
They contain no G-code or printer profile. Verify white/black spools and
printer settings before slicing. No physical-print trial is claimed.

Future builds belong in ignored `build/`, leaving this example set intact.
